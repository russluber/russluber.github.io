In this project, I analyzed UFC fight data to estimate how accurate each fighter is on average across their respective careers. To do this, I built a Bayesian multi-level logistic regression model, accounting for different sources of uncertainty of fighters' striking accuracy like gender, weight class, and fight-to-fight randomness.

You can find the GitHub repo [here](https://github.com/russluber/project-scrapyard).
